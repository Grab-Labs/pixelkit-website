# PixelKit Pro website

Public product, policy and support pages published by PixelKit Labs.

GitHub Pages publishes this static site from `main` at the repository root. It needs no installation or build step. Serve the folder over HTTP for local preview.

To update the public support address, edit the visible email and its `mailto:` value in `support.html`. The policy pages link to that contact section.

The screenshots depict the PixelKit Pro 1.0.0 Chrome workspace. Manrope is included under the SIL Open Font License in `assets/Manrope-OFL.txt`.
