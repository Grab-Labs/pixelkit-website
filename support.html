Report a public issue

Use GitHub Issues for public bug reports. Include the extension version, Chrome version, operating system, steps, and any error message. Use a non-sensitive example image if one helps.

Public issues are visible to everyone. Send personal information or sensitive details by email instead.

Troubleshooting

If a webpage scan finds few images, scroll to load lazy images and scan again. Chrome and the original host may limit which images can be saved.

If an image fails to import, check its actual format and try a smaller file. For large batches, export completed items and split the remaining files into smaller groups. Use Chrome Downloads to find exports.
