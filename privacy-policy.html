Privacy policy

Effective November 24, 2026. This policy covers PixelKit Pro 1.0.0 and the PixelKit Labs product website.

Local image processing

When you choose an image from your device, PixelKit Pro reads its filename, image contents and properties to perform the operation you request. Metadata inspection can display embedded information such as camera and GPS details. These data are processed on your device. PixelKit Pro does not upload your image contents, send them to its publisher, or use cloud processing. The extension includes no analytics, advertising, tracking, user registration or payment services.

Webpage scanning and downloads

The extension scans a tab only after you choose Scan this webpage from the toolbar popup. It reads that tab’s title and origin, image URLs, and available alt text, dimensions and sizes to build the gallery. It does not collect general browsing history. Gallery thumbnails may request images from their original hosts using Chrome’s normal image-loading behavior. Downloads request the selected image URLs from their original hosts. Requests omit cross-site credentials and PixelKit sets no referrer. When the original tab is still available, a same-origin fallback may use that webpage’s normal session credentials to fetch an image it can already read. The image hosts can receive normal connection information such as your IP address. PixelKit Pro sends no scan data to its publisher or an analytics service.

Storage and control

Your queue, gallery and output previews live in the workspace’s memory. Chrome session storage briefly holds scan results for the handoff from the popup and the workspace deletes them when read. If the handoff is interrupted, expired records may remain in Chrome session storage until a subsequent scan cleans them up, the extension reloads, or the browser session ends. Color theme preferences are saved in the Chrome profile until you reset extension data or uninstall the extension.

Exports are saved locally through Chrome. Chrome manages download files and download history. PixelKit Pro checks the status of the downloads it starts to release temporary file handles. It does not inspect general Chrome download history. You can close the workspace to clear its working data and use Chrome or your operating system to manage export files and download history.

Sharing, changes and contact

The extension publisher receives no extension telemetry or image data and does not share or sell them. Network requests to the original image hosts are described above. An updated policy will accompany material changes to how the extension handles data. For a privacy question or request, contact PixelKit Labs privately using the email on the Support page.

This website and support

This website uses no publisher-run analytics, advertising scripts, signup forms or payment fields. GitHub Pages hosts the site, and GitHub may process standard service data such as IP addresses and request details. Read GitHub’s privacy statement.

If you email us, PixelKit Labs uses your address and message to respond, troubleshoot and keep necessary support records. The email provider processes messages to deliver them. GitHub Issues is a public forum for non-sensitive bug reports. Use email for private information and remove personal details from sample files.

Purchases are currently unavailable. Before introducing a payment or activation provider, PixelKit Labs will update this policy to describe the relevant data and recipients.
